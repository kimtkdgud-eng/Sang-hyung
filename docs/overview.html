평가 조건 게이트

조건이 섞인 채로 분석하는 것을 막는다. 본체 v2.12 의 학습 데이터 선택은 metric+unit 만 보고 문자열 조건을 버린다(제안서: docs/PROPOSAL_protocol_gate_for_feature_hub.md).

차단: 고온저장/retention/용량 (%) 에 평가 조건이 2가지 섞여 있다. 조건 하나를 선택하세요(condition_key).

물성의 추가 예측 기여

같은 표본·모델·분할에서 비교. 조성 그룹 단위 분할, 사전 기준(MAE 개선 ≥ 0.5, 일관성 80%). 막대는 검증 MAE(작을수록 좋음).

물성 추가 개선이 사전 기준을 넘고 일관되다. 어떤 물성이 기여했는지(하나씩 제거 비교) 확인한 뒤 후속 실험·DOE 반영을 검토한다.

이 결과는 물성이 실측된 배치에서의 비교다. 아직 제조·측정하지 않은 후보에는 물성 입력이 없으므로 같은 개선이 적용된다고 해석하지 않는다. 합성 데이터 결과는 구조 확인용이다.

규칙 검토 예

  • 통과 1개: 연구자 승인 대기
  • VC 과다·용매 합계 90 제외 — [RANGE] VC: 5 wt% 가 허용 범위 0~3 밖; [SOLVENT_SUM] 용매 vol% 합계 90 (기준 100 ± 0.5)
  • 염을 wt% 로 표기 제외 — [UNIT] LiPF6: salt 는 mol/L 로 표기해야 한다(입력 wt%). 자동 환산하지 않는다

조성 단독 예측이며 실측·검증이 아니다. 외삽 위험이 높은 후보는 특히 주의한다. 모든 후보는 연구자 승인 전에는 실험 대상이 아니다.
